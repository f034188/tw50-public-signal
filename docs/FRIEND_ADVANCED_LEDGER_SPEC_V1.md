# 朋友進階版｜個人資金流、F/A 分帳與績效規格 v1（虛擬資料驗證）

**版本：2026-11-12／研究實作文件。公開儲存庫僅包含純虛構測資與參考程式，**沒有**任何朋友的真實庫存、薪資或帳號資訊。**

## 1. 進階版到底需要提供什麼？

初次使用仍然**只問一題**：「選擇①基礎版（不提供個人資料）或②進階版（自願提供股數／現金）？」未回答或不願提供就使用基礎版，不反覆索取資料。

進階版從**朋友自己選定的新起始日**建立 F/A 兩本虛擬子帳戶。最少資料：起始日、F 的 0050 股數／00631L 股數／可投資現金、A 的三項數字，以及每筆**之後**投入／提領資金的日期和金額。不能把合計持股推測成兩個帳戶各持有多少。歷史成本若不知道，仍可用起始日**已驗證市價**建立「從啟用日起」績效；**不能藉此推算啟用前的完整歷史報酬**。

如要以目前庫存轉入新模型，應先決定本人是否實際認列／買賣及分帳方式；不能把建議調整量列為已成交。可以接受零股（1 股整數），**不使用小數股**。每筆真實交易應由朋友確認成交日、股數、實際成交價與全部交易費用，否則視為**模型估算**而非真正已交易。

**不要詢問或儲存：**姓名、身分證、電話、完整薪水、銀行／證券帳號、券商登入密碼、Token、API key、存摺截圖。只問「本次確定可投資金額」而非薪資總額。朋友本人可以在自己 ChatGPT 內保留資料，也可以用自己的**私人檔案**維護；不得寫入本 Public repo 的檔案、Issue 或 Pages。

## 3. 記帳不可混淆的四種事件

1. **外部入金（DEPOSIT）**：本人工資、額外投入等，只增加現金與淨入金，**不算投資獲利**。預設新資金 F/A 各 50%，不是「優先補低側」那個尚未重新回測的新版本。
2. **外部出金（WITHDRAW）**：提出現金給本人使用，降低淨投入與資產，**不直接視為投資虧損**。必須現金充足；如要賣股先記錄成交後再提領，不能讓現金帳變成負值。
3. **子帳戶轉移（INTERNAL_TRANSFER）**：F 轉 A 或 A 轉 F 的**現金**，是內部再平衡，不算新薪資、不算提領，也不改變整體資產淨值。若要移轉股票市值歸屬，需另行定義並對帳，不能當成已成交。
4. **ETF 已成交買賣（BUY／SELL）**：包含實際股數、成交價和費用，按現金自融資入帳。沒有朋友確認的成交，不得改寫其實際庫存。研究模型計算的未來成交另設 **PAPER_PENDING**，不混入真實已成交帳。

所有事件必須有日期，交易要有唯一 ID，避免同日提醒或補送記帳重複；資料無法驗證時，顯示待查，保留上次可信快照。不能把「應賣」當「已賣」。

## 4. 配息與分割的處理

- **除息日（EX_DIV）**：在確定股數、每股股息、除息日與實際發放日都可靠時，建立「應收股利」，使除息價格下降不會被錯記成當天完整損失。
- **股息入帳日（DIVIDEND_PAID）**：應收股利轉成現金，**不再另外記一次報酬**。缺少除息應收紀錄則阻擋，避免憑空生錢。
- **分割日（SPLIT）**：要有核實的拆分比例，再換算**股數**；報價須使用新股數基準，**不能把拆分造成的原始價格下降當停損**。
- **停牌中**：可繼續讀 0050 的可靠市場訊號；若缺正式可得的 00631L NAV，F/A 估值只能標成暫估。停牌腿交易不算已成交；復牌後按有效價格與確認股數重新判斷。
- 反分割若產生畸零股而缺少現金結算規則，先阻擋而不是猜測。

**目前提供的公開 Python 是人工輸入可靠事件與價位的「參考記帳器」；不是全天候自動取得每個 ETF 公司行動與券商成交的成品。**

## 5. 三種不同的「報酬」

- **未實現加已實現淨損益（新台幣）**：最新帳戶淨值 − 起始日帳戶淨值 − 期間**淨外部入金**。例：從 100,000 投入，後來薪水再投入 10,000，最新淨值 111,000，正確淨損益是 **+1,000**，而不是 +11,000。
- **TWR（時間加權報酬）**：按每日市值與資金流時點拆出投資績效；適合跟策略模型比較。參考實作規定外部資金在**當日收盤時**有效，當日價格變化先計入前段、外部資金與交易成本在收盤後計算。若現實入金／成交在盤中且影響結果，需輸入額外的流入時點估值，不能冒充精確 TWR。
- **XIRR（資金加權年化報酬）**：將起始淨值視為起始資金支出、每筆外部入金為流出／提領為流入、最後的帳戶淨值視為終值；使用**實際日期**求年化根。多次資金流方向交錯可能沒有唯一解，則顯示無法可靠計算。
- **未滿 365 日**：以累計 TWR、淨損益為主；年化 TWR 與 XIRR 預設**不顯示**，避免短期報酬被放大。這是展示政策，不是說年化公式在短期不可運算。

**同一時間不能把 N21 的 33.25% XIRR 當成朋友啟用後的 TWR/XIRR。** N21 是另一個起點、不同現金流、不同時期的歷史研究。

## 6. 與 0050 買進持有對照

未來加入公開／進階比較時，對照組應從**同一啟用日期、相同外部存提款時間和金額**、使用可比較的交易成本與 0050 含息總報酬價格，按相同現金入帳規則買入持有。未做到這些之前顯示：

`0050 對照：資料尚未完成，不能計算`

不能只用 0050 當期價格漲跌對比有持續薪資入金的朋友帳戶；這會導致誤導。現階段參考引擎**故意不假造基準報酬數字**。

## 9. 個人隱私與免責

實際投入與買賣由本人自行決定；公開研究者不替朋友保管帳戶資料、簽署投資委任、下單或保證虧損上限。分享使用說明不構成當然免責；是否涉及須經許可的個人化投資建議取決於實際行為而非「僅供參考」四字。

**本方案的預設是資訊最小化：基礎版完全不必提供個人資料；進階版不蒐集識別資料，只利用朋友自願提供的必要股數與現金資訊做研究計算。**
