# N46｜朋友進階版：私人帳本 → 本人 ChatGPT 每日提醒（可驗證交接規格）

研究日期：**2026-11-12**。此版本是**可測試的交接機制與風險規格**，不是自動讀取券商帳戶或自動建立朋友排程的完成版。公開儲存庫只放程式與**虛構測資**；絕不能提交朋友的股數、薪資投入、帳本或 Token。

## 1｜架構與責任界線

```text
                     不含個資的公開訊號（N43/N44）
                       tw50-public-signal/market.json
                                       │
                                     讀取
                                       │
朋友自己控制的「私有庫存帳本」  →  朋友自己的 ChatGPT 排程
(完全與分享者無關; optional)                │
       ├─已確認的成交／現金流                 ├─市場版：加碼候選／減碼候選／不動／資料待查
       ├─F/A 兩帳股數與現金                  ├─資料可核對才算個人配置、報酬
       └─最後本人確認日期                    └─資料不齊就降成基礎版，不猜張數
```

**不要把朋友的帳本寫進**本公開 GitHub 的 `site/`、`docs/`、`examples/`、Issue、Discussion 或 Pages。私人資料由**朋友自己**管理，策略分享者不需要也不應取得他們的私有 Repo 權限。

### ChatGPT 排程的實際功能限制

OpenAI 的[排程任務官方說明](https://help.openai.com/zh-hant/articles/10291617-scheduled-tasks-in-chatgpt)確認：**符合資格帳號**的排程任務可以使用已授權連結的 GitHub 等應用程式，但必須符合朋友自己的方案、應用程式授權、可使用功能及帳號設定。

**特別注意**：在 ChatGPT Project 中建立的排程，不能假設能存取該 Project 裡已上傳的檔案。手機與電腦的本機 JSON 檔也不能因為使用者建立了排程，就被自動讀取。**目前沒有對真正朋友的私人 Repo、連結權限或每日 08:00 排程進行端對端實測，不能宣稱已全自動完成。**

最終朋友版的「可被自己排程讀取」設計有兩種：

- **進階版－自行同步**：朋友可選擇自己管理一個 **Private GitHub repo**，只放自己想要讓其 ChatGPT 讀取的「私人交接摘要」；朋友自己的 ChatGPT 若能連結並獲其明確授權，就可以在排程時嘗試讀取。第一次仍須進行真實的權限與排程驗收，才能啟用個人化。
- **進階版－手動載入**：朋友在自己的 ChatGPT 對話中提供最新私人摘要。無法證明排程之後能取得檔案時，就**不承諾**每天自動讀取持股，改為基礎版提醒加一則「請自行核對庫存」的文字。

不需要分享者持有朋友的帳號、SSH Key、GitHub Personal Access Token，朋友也不要把它貼進聊天。與持股無關的共同市場資訊直接從公開網站取得。

## 2｜先保護資產隱私，再考慮準確性

朋友可選擇不使用私人交接；基礎版永久開放。若選進階版，資料最小化為：
- **私有的 F、A 兩帳已確認股數與可投資現金**（可能包含明細金額）；
- 最新完成收盤的**估值日期**；
- 最後一次本人確認「實際成交與入出金都記妥」的日期；
- 個人帳本版本、SHA256 摘要，以及從本人私人帳本重算的 TWR／XIRR（可算時）。

**沒有必要**提交姓名、身分證、銀行帳號、薪資單、券商登入資料、密碼、API 金鑰、券商授權或朋友的全部家計資料。選用 Private GitHub 存儲時，是把財務資訊託管給自己選擇的雲端服務，應自行評估隱私條款、存取權和撤銷方式；**Private 不等於端到端加密**。

目前的 SHA256 用來偵測**意外更動**，不是身份驗證、加密、數位簽章，也不能保證資料來源真實。本人須確認庫存並定期備份。

## 3｜N46 的兩個工具

- [本機 N45 私人接續器](../tools/friend_private_local_ledger.py) —— 透過手動確認後的交易日更新私有帳本，拒絕重複日／猜測成交；只寫入使用者自己保護的資料夾。
- [N46 私有交接匯出與每日安全判定](../tools/friend_n46_private_handoff.py) —— 把 N45 已完成驗證的帳本縮成一份私有摘要，標明「已估值交易日」與「本人最後確認持倉日」，並以公開市場訊號作**只讀交叉檢查**。

**匯出範例**（請用自己裝置上的私人路徑，絕不要把真實檔案提交到 Public repo）：

```bash
python tools/friend_n46_private_handoff.py export \
  --source /private/account.json \
  --private-output /private/handoff.json \
  --owner-confirmed-through YYYY-MM-DD
```

`YYYY-MM-DD` 代表使用者已確認股票持股、現金及入出金無遺漏的日期；不能把未核對日寫成已確認。此程式**不會**自動更新到 GitHub 或 ChatGPT。需要同步至朋友自己授權的 Private repo 時，也必須由**朋友本人**配置、審核並執行，不使用分享者的 GitHub Token。

**每日安全判定示意**：

```bash
python tools/friend_n46_private_handoff.py check \
  --public-market-json /path/market.json \
  --private-snapshot /private/handoff.json \
  --on-date YYYY-MM-DD
```

輸出只有**狀態、日期與可否顯示個人模型估算**的布林值；不會把私人股數直接印進普通日誌。

## 4｜每日 08:00 的資料驗收規則

| 狀況 | 允許的提醒 | 不可宣稱 |
|---|---|---|
| 公開訊號有效，但沒有私人資料 | **基礎版**市場方向與 F/A 目標比例 | 不可捏造個人股數、現金、實際報酬 |
| 公開訊號因過期、分割、來源異常而不可判 | **資料待查**，解釋最後有效日期 | 不可拿上次的趨勢當新的減碼事件 |
| 私人交接是虛構測試檔 | **僅測試，不是本人持倉** | 不可計算真正的個人買賣張數 |
| 私人檔版本/摘要不符 | **退回基礎版**，請使用者修復檔案 | 不可默默忽略錯誤 |
| 私人帳本估值日期落後最新交易日 | 市場方向照常、個人績效**待更新** | 不可用舊價偽裝今天淨值 |
| 個人股數與現金已由本人核對到最新市場日，且當日報價有效 | 可顯示「**模型待調整股數／金額**」與個人績效 | 不可聲稱已下單或買賣一定成交 |

**雙重確認是必要的**：①行情是最近已驗證的有效收盤日，②本人確定股數／新入金／已成交都沒有漏記。兩者只要有一個無法驗證，就不提供精確的加減碼股數。

這是**保守的完成條件**；即使朋友幾天都沒有交易，單靠前幾天的舊帳本也不能自動證明今天沒有新增入金或異動，除非朋友另行明確確認。為了可靠性，朋友可以選擇偶爾更新；沒有最新個人帳本的早晨就收到基礎版而不是錯誤的進階版。

## 5｜個人資金入帳提醒怎麼顯示

當朋友表示「我的本次可投資資金 20,000 元**已實際入帳**」，才算入進階帳本。沒有說的時候不自行推測薪轉金額或日期。

- **已確認入帳但尚未成交**：顯示 20,000 元是可投資現金，照 F/A 50:50 的原規則給**配置候選**；實際是否買進須本人另外確認。
- **本人回報已成交**：記錄股數、價格、費用和交易日，後續才會反映資產帳本。
- **資料仍未更新**：保留最後可信記錄，私人比例及報酬標註待核，不反覆把同一筆薪水當作新投入。
- **如果改成新資金先補偏低策略**：標示新版本、原 5pp 歷史績效不直接適用，需另行回測。

## 6｜目前完成及尚未完成

**N46 已完成：**只讀、無網路的私有摘要匯出和公開＋私人資料時間一致性檢查；用純虛構資料測試過逾期行情、私人摘要改動、重複欄位／未知版本、真實／測試帳本的區分、持倉與估值日不一致時禁算新張數等。

[**GitHub Actions Run 43192472911**](https://github.com/f034188/tw50-public-signal/actions/runs/43192472911) 驗收成功：F/A 帳務 20 項、0050 同現金流對照 17 項、私有原子化接續 15 項、N46 私人交接 18 項，**合計 70/70 項通過**。這些皆為純虛構資料測試，沒有朋友真實庫存，也不是實際 ChatGPT 連接驗收。

**尚未完成：**
1. 朋友自己開一個 Private repo 並連結到**自己的** ChatGPT GitHub App 權限。
2. 在朋友帳號，實際測試其排程能不能讀到 Private repo 最新摘要；若不能，不能宣稱進階版已全自動。不同帳號方案／管理員授權可能有差異。
3. 若要真正每日績效，仍需要最新官方收盤、00631L 配息與分割等完整公司行動、個人交易與現金流；公開網站**只提供市場方向**，不是私人逐日估值引擎。
4. 0050 對照組需同日可信行情、股息、分割與交易成本，不能用 N21 老回測直接代替新朋友啟用後的績效。
5. N46 無券商介面、不代下單，不保管財產，也沒有被額外啟用任何 ChatGPT 定時任務。

**總結**：只要共同市場訊號可用，基礎版的每日提醒就可以獨立運作。進階版可以循序提供更多資料，但不能讓「方便分享」犧牲持股隱私或數字真實性。
